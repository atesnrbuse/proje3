# Mini Görev Yönetim Sistemi

Konsol üzerinden kullanıcıların görev ekleyebildiği, mevcut görevleri numaralandırılmış şekilde listeleyebildiği ve seçilen numaraya göre görev silebildiği basit bir CLI(Komut Satırı Arayüzü) uygulaması.

---

## Özellikler

- **Görev Ekleme:** Yeni görev metinlerini dinamik olarak listeye kaydetme.
- **Görev Listeleme:** Eklenen tüm görevleri sırasıyla numaralandırarak (`enumerate`) görüntüleme.
- **Görev Silme:** Kullanıcının girdiği sıra numarasına göre listeden görev çıkarma.
- **İnteraktif Menü:** Kullanıcı çıkış yapana kadar devam eden konsol menüsü.

---

## Kullanılan Teknolojiler

- **Dil:** Python
- **Kullanılan Yapılar:**
  - Fonksiyonlar (`def`)
  - Döngüler (`while True`, `for`)
  - Karar Yapıları (`if-elif-else`)
  - Liste İşlemleri (`list`, `append()`, `pop()`, `len()`)
  - Konsol Girdi/Çıktı Fonksiyonları
